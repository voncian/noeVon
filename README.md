# 웨이트 카운터

웨이트 트레이닝 중 종목별 세트 횟수를 카운트하고, 세트 간 휴식 시간을 재주는 모바일 웹 앱(PWA)입니다.

## 주요 기능

- **부위별 종목 계층 구조**: 상체(가슴/등/어깨/팔), 하체(대퇴사두근/햄스트링·둔근/종아리/코어) 순으로 종목을 선택합니다.
- **종목 직접 추가**: 목록에 없는 종목은 원하는 그룹에 직접 추가할 수 있습니다.
- **세트 · 횟수 · 휴식 시간 직접 설정**
  - 세트 수: 1 ~ 10세트
  - 목표 횟수: 10 ~ 30회
  - 휴식 시간: 10초 단위, 10 ~ 300초
- **세트 카운트 & 휴식 타이머**: "세트 완료" 버튼으로 세트를 기록하면 자동으로 휴식 타이머가 시작되고, 종료 시 진동·알림음으로 알려줍니다.
- **운동 기록**: 완료한 운동은 날짜별로 자동 저장되어 기록 화면에서 확인할 수 있습니다.
- 오프라인에서도 사용할 수 있는 PWA (홈 화면에 추가 가능)입니다.

## 실행 방법

빌드 과정 없이 정적 파일로 동작합니다.

```bash
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```

모바일 브라우저에서 "홈 화면에 추가"를 사용하면 앱처럼 설치해서 사용할 수 있습니다.

## 파일 구조

- `index.html` — 화면 마크업 (홈 / 설정 / 운동 / 완료 / 기록)
- `style.css` — 스타일
- `app.js` — 앱 로직 (종목 데이터, 상태 관리, 타이머, localStorage 저장)
- `manifest.webmanifest`, `sw.js`, `icons/` — PWA 설정
